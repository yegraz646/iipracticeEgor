# Parking AI — обнаружение занятых парковочных мест


**Единственная функция программы:** обнаруживать автомобили на загруженной фотографии и выделять каждый найденный автомобиль красной рамкой, свободное на парковке соответственно свободно. Сделать задачу согласно правилам ПДД я к сожалению не смог.


## Запуск в PyCharm (Windows)

1. Распакуйте архив.
2. Откройте в PyCharm папку `parking_ai_project` — ту, в которой находятся `app.py` и `requirements.txt`.
3. Откройте вкладку **Terminal** внизу PyCharm.
4. Выполните команды по очереди:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

## Локальные адреса

После запуска приложения откройте в браузере любой из адресов:

- http://127.0.0.1:5000
- http://localhost:5000

Оба адреса ведут к приложению на этом компьютере. Сервер должен оставаться запущенным, пока вы пользуетесь сайтом.

## Как пользоваться

1. Откройте сайт по локальному адресу.
2. Нажмите **«Выберите фотографию парковки»**.
3. Выберите изображение в формате JPG, JPEG, PNG или WEBP.
4. Нажмите **«Проанализировать фотографию»**.
5. На результате автомобили будут отмечены красными рамками; ниже будет показано количество обнаруженных автомобилей.

При первом запуске библиотека Ultralytics может загрузить файл весов `yolov8n.pt`. Поэтому для первой установки зависимостей и первого запуска нужен интернет.

## Основные файлы

- `app.py` — веб-сервер Flask и загрузка фотографий.
- `parking_analyzer.py` — обнаружение автомобилей моделью YOLO и отрисовка красных рамок.
- `templates/index.html` — веб-страница приложения.
- `static/app.js` — загрузка фотографии и отображение результата.
- `static/style.css` — оформление страницы.
- `requirements.txt` — необходимые библиотеки Python.

## Ограничения

Точность обнаружения зависит от качества фотографии, освещения, ракурса, размера автомобилей на снимке и перекрытий. Программа обнаруживает транспортные средства на изображении, а не определяет фактическую занятость парковочных ячеек по разметке.
